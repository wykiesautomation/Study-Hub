# StudyHub Go-Live Website

GitHub Pages ready website for StudyHub.

## Upload
Upload this ZIP content to the repo root, commit to `main`, then enable GitHub Pages from `main / root`.

## Backend
Apps Script files are in `/apps_script`. Do not serve them as web pages.

## Secrets
Do not put PayFast merchant key or passphrase in GitHub. Store them in Apps Script Properties only.

## Paper and Memo Pipeline Update
This package includes `apps_script/` with an approved-source discovery and reliable paper/memo download pipeline. See `apps_script/README_BACKEND_SETUP.md`.
